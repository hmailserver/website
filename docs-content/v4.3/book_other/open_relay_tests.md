As soon as you finish installing and configuring hMailServer, you should run some open relay tests. It ensures that your server will not be used for spamming.

- [http://members.iinet.net.au/~remmie/relay/](http://members.iinet.net.au/~remmie/relay/)
- [http://www.aupads.org/test-relay.html](http://www.aupads.org/test-relay.html)
- [http://www.abuse.net/relay.html](http://www.abuse.net/relay.html)
