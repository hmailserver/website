The IPHome object contains an IP address that hMailServer should use when multihoming is enabled.

# Version

The below documentation is valid for hMailServer 4.2 and later.

# Properties

#### Property ID As Long

<div class="indented">
The database identifier for the IPHome object.
</div>

#### Property IPAddress As String

<div class="indented">The IP address.</div>

# Methods

#### Sub Save()

<div class="indented">Saves the IP address in the database.</div>
