The RouteAddress object represents an recipient address in the route settings.

*The below documentation is valid for hMailServer 4.x and later*

# Properties

#### Property Address As String

<div class="indented">The email address.</div>

#### Property ID As Long

<div class="indented">The database identifier for this address.</div>

#### Property RouteID As Long

<div class="indented">The ID of the route that this address is connected to.</div>

#### Sub Save()

<div class="indented">Saves the object in the database.</div>
