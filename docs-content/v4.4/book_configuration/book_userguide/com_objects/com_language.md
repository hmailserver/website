The language object is used by the hMailServer user interface to retrieve translated strings. Both hMailAdmin and PHPWebAdmin uses the Language object to retrieve all strings that should be shown.

# Version

The below documentation is valid for hMailServer 4.2 and later.

# Properties

#### Property String(StringID As Long) As String

<div class="indented">Returns a translated string by it's ID</div>
