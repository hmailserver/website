The DomainAlias object represents an alias of a hMailServer domain.

# Version

The below documentation is valid for hMailServer 4.1 and later.

# Properties

#### Property AliasName As String

<div class="indented">The domain alias.</div>

#### Property DomainID As Long

<div class="indented">The database identifier for the domain that this alias is connected to.</div>

#### Property ID As Long

<div class="indented">The database identifier for the object.</div>

# Methods

#### Sub Save()

<div class="indented">Saves the IP address in the database.</div>
