The BackupSettings object holds the settings for the hMailServer backup.

# Version

The below documentation is valid for hMailServer 4.2 and later.

# Properties

#### Property BackupDomains As Boolean

<div class="indented">Backup domains when a backup is made.</div>

#### Property BackupMessages As Boolean

<div class="indented">Backup messages when a backup is made.</div>

#### Property BackupSettings As Boolean

<div class="indented">Backup settings when a backup is made.</div>

#### Property CompressDestinationFiles As Boolean

<div class="indented">Compress the destination files when a backup is made.</div>

#### Property Destination As String

<div class="indented">The destination folder of the hMailServer backups.</div>

#### Property LogFile As String

<div class="indented">The log file that contains the backup log.</div>
