The *Recipients* collection contains zero or more recipients. The recipients collection is normally connected to a specific e-mail message.

# Version

The below documentation is valid for hMailServer 4.2 and later.

# Properties

#### Property Count As Long

<div class="indented">
The number of recipients in this collection.
</div>

#### Property Item(Index As Long) As [Recipient](?page=com_recipient)

<div class="indented">
Returns the Recipient by an given index.
</div>
