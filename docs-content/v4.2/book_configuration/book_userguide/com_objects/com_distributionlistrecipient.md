The DistributionListRecipient object represents an recipient of a hMailServer distribution list.

# Version

The below documentation is valid for hMailServer 4.0 and later.

# Properties

#### Property ID As Long

<div class="indented">The database identifier for the distribution list folder.</div>

#### Property RecipientAddress As String

<div class="indented">The email address of the recipient.</div>

# Methods

#### Sub Save()

<div class="indented">Saves the recipient.</div>

#### Sub Delete()

<div class="indented">Deletes the recipient.</div>
