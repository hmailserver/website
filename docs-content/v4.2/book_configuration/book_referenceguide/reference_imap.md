<h3>TCP Port / IMAP port

<div class="indented">
This setting lets you define what TCP/IP port the hMailServer IMAP server should listen on. By default, port 143 is used. You should normally not change this setting.
</div>

<h3>Other / Welcome message</h3>

<div class="indented">
The welcome message is sent to IMAP clients directly after they connect to the server. One reason to change this message is if you don't want anyone to know what kind of server software you are using. 
</div>
