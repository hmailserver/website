The server technology and overall design of hMailServer is in the hands of [Martin Knafve](mailto:martin@hmailserver.com). hMailServer uses a couple of third-party components and libraries:

- PHPWebAdmin is originally written by Steen Rabøl
- Mime encoding / decoding by Jeff Lee
- MD5 algorithm by RSA Data Security
- Blowfish algorithm by Bruce Schneier
- Translation, a lot of people. List up soon.
- Progress bars by [VBAccelerator](http://vbaccelerator.com/)
- SPF library by Roger Moser
- Boost by [boost.org](http://boost.org)
- Winsock, ATL, ADO etc by [Microsoft](http://www.microsoft.com)
- InnoSetup by [JR Software](http://www.jrsoftware.org/)
- MySQL++ by a [couple of people](http://tangentsoft.net/mysql++/).
- LibMySQL by [MySQL AB](http://www.mysql.com/).

Some progressbars are Copyright (c) 2002 vbAccelerator.com.
