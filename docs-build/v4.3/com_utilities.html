The utilities object contains different utilities that can be used by hMailServer COM API clients.

Version

The below documentation is valid for hMailServer 4.2 and later.

Methods

Function BlowfishDecrypt(Input As String) As String

Decrypts a string that has been encrypted by hMailServer.

Function BlowfishEncrypt(Input As String) As String

Encrypts a string.

Function EmailAllAccounts(sRecipientWildcard As String, sFromAddress As String, sFromName As String, sSubject As String, sBody As String) As Boolean

Sends an email to a group of accounts. The sRecipientWildcard specifies what addresses to send to. sFromAddress is the sender address. sFromName is the name put in the From header. sSubject is the subject of the message, and sBody is the body.

Function GenerateGUID() As String

Returns a unique ID.

Function GetMailServer(EMailAddress As String) As String

Returns the email server handling email for the given address.

Function ImportMessageFromFile(sFilename As String, iAccountID As Long) As Boolean

Import a message file from the disk and put's it in the account with the given ID. The message will be put in the inbox.

Function IsValidDomainName(sDomainName As String) As Boolean

Returns true if the given string is a valid domain name.

Function IsValidEmailAddress(EMailAddress As String) As Boolean

Returns true if the given string is a valid email address.

Sub MakeDependent(OtherService As String)

Makes the hMailServer service dependent on another service.

Function MD5(Input As String) As String

Returns a MD5 hex string for the given string.

Sub RunTestSuite(sTestPassword As String)

Runs the hMailServer test suite. This should only be run by hMailServer developers since it will reset your entire hMailServer installation and create test objects.
