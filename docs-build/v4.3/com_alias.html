Version

The below documentation is valid for hMailServer 4.2 and later

Properties

Property Active As Boolean

If the alias is active, true is returned. Otherwise false.

Property DomainID As Long

Returns the unique identifier for the domain which this alias is connected to.

Property ID As Long

Returns the unique identifier for this alias.

Property Name As String

Returns the name of this alias.

Property Type As Long

Returns the type of alias. Currently, this is always zero.

Property Value As String

Returns value of the alias. Emails sent to this alias will be forwarded to this address.

Methods

Sub Delete()

Deletes the alias from the database.

Sub Save()

Saves the alias to the database..
