Signature

OnDeliverMessage(oMessage as hMailServer.Message)

Result values

  • 0 - Deliver the message
  • 1 - Do not deliver the message

Examples

VB-script:

Sub OnDeliverMessage(oMessage)

  If oMessage.Size > 1000000 Then
     ' This message is to big. We should not
     ' deliver it.
     Result.Value = 1            
  Else
     ' Accept the message
     Result.Value = 0 
  End If

End Sub
