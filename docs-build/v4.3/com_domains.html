The Domains collection contains zero or more domains.

Version

The below documentation is valid for hMailServer 4.2 and later.

Properties

Property Count As Long

The number of domains in this collection.

Property Item(Index As Long) As Domain

Property ItemByDBID(DBID As Long) As Domain

Function ItemByName(ItemName As String) As Domain

Returns the domain by it's given Index, database identifier or name. If the domaindoes not exist, an exception is thrown.

Methods

Function Add() As Domain

Creates and returns a new domain. Call Save() on the returned domain to add it to the collection.

Sub Refresh()

Refreshes the collection from the database.
