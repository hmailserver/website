The RouteAddresses collection contains the email addresses connected to a hMailServer route.

Version

The below documentation is valid for hMailServer 4.1 and later.

Properties

Property Count As Long

The number of objects in the collection.

Property Item(Index As Long) As RouteAddress

Returns an RouteAddress from the collection based on it's index in the collection.

Property ItemByDBID(DBID As Long) As RouteAddress

Returns an RouteAddress from the collection based on it's database identifier.

Methods

Function Add() As RouteAddress

Adds a new IP address to the collection.

Sub DeleteByDBID(DBID As Long)

Deletes the given email address from the collecton.

Sub DeleteByDBID(DBID As Long)

Deletes the email address with the specified database identifier.
