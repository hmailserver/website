The scripting object contains properties that relates to hMailServer scripting.

Version

The below documentation is valid for hMailServer 4.x and later.

Properties

Property Directory As String

Path to the events directory

Property Enabled As Boolean

Enable script server

Property Language As String

The scripting language

Methods

Sub Reload()

Reloads the script from the event directory.

Function CheckSyntax() As String

Compiles the script in the event directory and returns the result.
