The GlobalObjects object contains objects that are global to the entire hMailServer installation and needs to be accessible using the COM API.

Version

The below documentation is valid for hMailServer 4.2 and later.

Properties

Property DeliveryQueue As DeliveryQueue

The hMailServer delivery queue. Contains properties to clear the queue etc.

Property Language(sLanguage As String) As Language

The language object. Used to retrieve translated for the user interface.
