The AntiVirus object holds settings for hMailServer anti virus protection.

Version

The below documentation is valid for hMailServer 4.2 and later.

Properties

Property Action As eAntivirusAction

Action to take when a virus is found.

Property ClamWinDBFolder As String

The folder that contains the ClamWin database.

Property ClamWinEnabled As Boolean

ClamWin anti virus protection is enabled.

Property CustomScannerEnabled As Boolean

Custom anti virus scanner is enabled.

Property CustomScannerExecutable As String

The path to the custom anti virus scanner command line executable.

Property CustomScannerReturnValue As Long

The value that the custom anti virus scanner will return if a virus is found.

Property NotifyReceiver As Boolean

hMailServer should notify the recipient of the email message if a virus is found.

Property NotifySender As Boolean

hMailServer should notify the sender of the email message if a virus is found.
