The Route object represents a hMailServer route.

Version

The below documentation is valid for hMailServer 4.2 and later.

Properties

Property Addresses As RouteAddresses

A collection containing the valid email addreses for this route.

Property AllAddresses As Boolean

hMailServer should route to all addresses.

Property DomainName As String

The route domain name.

Property ID As Long

The database identifier for the route.

Property MinutesBetweenTry As Long

Number of minutes between every try when delivering to the route SMTP server.

Property NumberOfTries As Long

The number of times hMailServer should try to deliver to the route SMTP server.

Property RelayerAuthUsername As String

The username hMailServer should use when delivering messages (if relayer requires SMTP authentication).

Property RelayerRequiresAuth As Boolean

The SMTP server used for the route requires SMTP authentication.

Property TargetSMTPHost As String

The SMTP server hMailServer should deliver to when delivering to this route.

Property TargetSMTPPort As Long

The TCP/IP port on the target SMTP server hMailServer should deliver to when delivering to this route.

Property TreatSecurityAsLocalDomain As Boolean

hMailServer should treat this route as a local domain when checking security against IP ranges.

Methods

Sub Save()

Saves the route in the database.

Sub SetRelayerAuthPassword(newVal As String)

Sets the password in the database.
