The DomainAlias object represents an alias of a hMailServer domain.

Version

The below documentation is valid for hMailServer 4.1 and later.

Properties

Property AliasName As String

The domain alias.

Property DomainID As Long

The database identifier for the domain that this alias is connected to.

Property ID As Long

The database identifier for the object.

Methods

Sub Save()

Saves the IP address in the database.
