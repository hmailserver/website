The DeliveryQueue object contains methods used to access the delivery queue.

Version

The below documentation is valid for hMailServer 4.2 and later.

Methods

Sub Clear()

Clears the delivery queue. Removes all the messages from the database and from the data folder.

Sub ResetDeliveryTime(iMessageID As Long)

Resets the delivery time for the message ID. This will cause hMailServer to deliver the message.

Sub StartDelivery()

Forces the deliverer to look for messages to deliver.
