The Messages collection contains messages.

Version

The below documentation is valid for hMailServer 4.2 and later.

Properties

Property Count As Long

The number of objects in the collection.

Property Item(Index As Long) As Message

Returns a message from the collection based on it's index in the collection.

Property ItemByDBID(DBID As Long) As Message

Returns a message from the collection based on it's database identifier.

Methods

Sub DeleteByDBID(DBID As Long)

Deletes a message from the collection (and database) based on it's database identifier.
