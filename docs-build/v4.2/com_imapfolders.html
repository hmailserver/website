The IMAPFolders collection contains zero or more IMAP folders.

Version

The below documentation is valid for hMailServer 4.2 and later.

Properties

Property Count As Long

The number of IMAP folders in this collection.

Property Item(Index As Long) As IMAPFolder

Property ItemByDBID(DBID As Long) As IMAPFolder

Property ItemByName(Name As String) As IMAPFolder

Returns the imap folder by it's given Index, database identifier or name. If the IMAP folder does not exist, an exception is thrown.
