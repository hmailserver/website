The DistributionLists collection contains the distribution lists connected to the parent domain.

Version

The below documentation is valid for hMailServer 4.0 and later.

Properties

Property Count As Long

The number of objects in the collection.

Property Item(Index As Long) As DistributionList

Returns a distribution list from the collection based on it's index in the collection.

Property ItemByAddress(sAddress As String) As DistributionList

Returns a distribution list from the collection based on it's email address.

Property ItemByDBID(DBID As Long) As DistributionList

Returns a distribution list from the collection based on it's database identifier.

Methods

Function Add() As DistributionList

Adds a new distribution list to the collection.

Sub DeleteByDBID(DBID As Long)

Deletes the distribution list with the specified database identifier.

Sub Refresh()

Refreshes the collection from the database.
