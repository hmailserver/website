The Database object contains methods and properties that are needed for database access.

Version

The below documentation is valid for hMailServer 4.2 and later.

Properties

Property CurrentVersion As Long

The current hMailServer database. This value is stored in the table hm_dbversion

Property DatabaseType As eDBtype

The database server type.

Property RequiredVersion As Long

The database version hMailServer requires to run.

Methods

Sub ExecuteSQL(sSQLStatement As String)

Executes an SQL statement in the hMailServer database.

Function UtilGetFileNameByMessageID(MessageID As Long) As String

This method returns a value by the given message database ID.

Sample code

Display the current database version

`Dim obBaseApp Set obBaseApp = CreateObject("hMailServer.Application")

Dim obDatabase set obDatabase = obBaseApp.Database

MsgBox "hMailServer database version: " & obDatabase.CurrentVersion`
