The SecurityRanges collection contains the security ranges / IP ranges that hMailServer use.

Version

The below documentation is valid for hMailServer 4.2 and later.

Properties

Property Count As Long

The number of objects in the collection.

Property Item(Index As Long) As SecurityRange

Returns a security range from the collection based on it's index in the collection.

Property ItemByDBID(DBID As Long) As SecurityRange

Returns a security range from the collection based on it's database identifier.

Property ItemByName(sName As String) As SecurityRange

Returns a security range from the collection based on it's name.

Methods

Function Add() As SecurityRange

Adds a new security range to the collection.

Sub Delete(Index As Long)

Deletes an object in the database by it's index in the collection.

Sub DeleteByDBID(DBID As Long)

Deletes an object in the collection based on it's database identifier.

Sub Refresh()

Refreshes the collection.
