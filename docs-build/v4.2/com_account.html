Version

The below documentation is valid for hMailServer 4.2 and later

Properties

Property Active As Boolean

If the account is active, true is returned. Otherwise false.

Property ADDomain As String

The active directory domain this account is connected to. If the account is not connected to a domain, this returns an empty string

Property Address As String

The address of this account. Includes the domain name

Property AdminLevel As eAdminLevel

The administration level for this account.

Property ADUsername As String

The active directory username this account is connected to.

Property DomainID As Long

The ID of the domain this account is connected to.

Property FetchAccounts As FetchAccounts

External fetch accounts connected to this account.

Property ID As Long

The database identifier for the account.

Property IMAPFolders As IMAPFolders

Returns a collection of the IMAP folders owned by this account.

Property IsAD As Boolean

True if the account is connected to active directory. False otherwise.

Property MaxSize As Long

Maximum size of the account (MB).

Property Messages As Messages

A collection of the messages connected to the accounts mailbox.

Property Password As String

The password of this account. Might be encoded using MD5.

Property QuotaUsed As Long

Percentage of quota used. A value between 0 and 100. (4.2 and later)

Property Rules As Rules

A collection of the rules connected to this account.

Property Size As Long

The current size of this account.

Property VacationMessage As String

The vacation message for this account.

Property VacationMessageIsOn As Boolean

True if the vacation message is activated.

Property VacationSubject As String

The vacation subject for this account.

Methods

Sub DeleteMessages()

Deletes all messages connected to this account.

Sub Save()

Saves the account in the database.

Sub ValidatePassword(Password As String) as Boolean

Used to validate a users password. Returns true if the given password is correct.
