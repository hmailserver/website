The server technology and overall design of hMailServer is in the hands of Martin Knafve. hMailServer uses a couple of third-party components and libraries:

  • PHPWebAdmin is originally written by Steen Rabøl
  • Mime encoding / decoding by Jeff Lee
  • MD5 algorithm by RSA Data Security
  • Blowfish algorithm by Bruce Schneier
  • Translation, a lot of people. List up soon.
  • Progress bars by VBAccelerator
  • SPF library by Roger Moser
  • Boost by boost.org
  • Winsock, ATL, ADO etc by Microsoft
  • InnoSetup by JR Software
  • MySQL++ by a couple of people.
  • LibMySQL by MySQL AB.

Some progressbars are Copyright (c) 2002 vbAccelerator.com.
