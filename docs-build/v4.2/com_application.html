The Application object is the root object in the hMailServer COM hirearchy. Via this object, you can access all properties, settings and objects in your hMailServer installation.

Version

The below documentation is valid for hMailServer 4.2 and later.

Properties

Property BackupManager As BackupManager

Returns the backup manager. Contains backup settings and functions to initiate backup and restore tasks.

Property Database As Database

Returns an instance of the database object. Used check database version, run SQL statements etc.

Property Domains As Domains

Returns a collection of all the domains. Use this to access domains, accounts, aliases, distribution lists, etc.

Property GlobalObjects As GlobalObjects

Miscilaneous global objects, such as the delivery queue.

Property InitializationFile As String

The hMailServer.ini hMailServer is currently using.

Property Rules As Rules

Returns a collection containing all global rules.

Property ServerState As eServerState

Returns the current state of the server.

Property Settings As Settings

Returns an instance of the settings object. Use this to modify server settings such as TCP/IP ports, virus scanning, black lists etc.

Property Status As Status

Returns the status object. This object contains server metrics such as delivered messages, number of viruses detected etc.

Property Utilities As Utilities

Returns the Utilities object. This object contains misc functions, such as decrypting, MD5 routines, test suites, GUID generator and more.

Property Version As String

The hMailServer version.

Sample code

Display the current version

`Dim obBaseApp Set obBaseApp = CreateObject("hMailServer.Application")

MsgBox "hMailServer version: " & obBaseApp.Version`
