The Logging object holds the logging settings.

Version

The below documentation is valid for hMailServer 4.2 and later.

Properties

Property AWStatsEnabled As Boolean

AWStats logs should be created by hMailServer.

Property Device As eLogDevice

The logging device. Currently only hLogDeviceFile (2).

Property Directory As String

The hMailServer log directory.

Property Enabled As Boolean

Logging is enabled.

Property LiveLog As String

Returns the current content of the live log and then empties it.

Property LogApplication As Boolean

Application-level events should be logged.

Property LogDebug As Boolean

Debug-level events should be logged.

Property LogFormat As eLogOutputFormat

This property is not used.

Property LogIMAP As Boolean

IMAP-level events should be logged.

Property LogPOP3 As Boolean

POP3-level events should be logged.

Property LogSMTP As Boolean

SMTP-level events should be logged.

Property LogTCPIP As Boolean

TCP/IP-level events should be logged.

Methods

Sub EnableLiveLogging(newVal As Boolean)

Enable live logging.
