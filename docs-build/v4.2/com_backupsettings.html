The BackupSettings object holds the settings for the hMailServer backup.

Version

The below documentation is valid for hMailServer 4.2 and later.

Properties

Property BackupDomains As Boolean

Backup domains when a backup is made.

Property BackupMessages As Boolean

Backup messages when a backup is made.

Property BackupSettings As Boolean

Backup settings when a backup is made.

Property CompressDestinationFiles As Boolean

Compress the destination files when a backup is made.

Property Destination As String

The destination folder of the hMailServer backups.

Property LogFile As String

The log file that contains the backup log.
