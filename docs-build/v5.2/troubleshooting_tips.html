Below are some tips that can be useful if you run into problems with hMailServer. If you can't find the answer in any of the links, ask your question in the hMailServer Forum.

General tips

  • I can't start the server
  • I can't connect to the server using my e-mail client
  • I can't send messages to addresses outside the server
  • I can't send messages to specific servers, such as Google or Yahoo.
  • I can't receive e-mail messages from other servers
  • My server says "incorrect password"
  • My Outlook crashes or gives an error message
  • Someone seems to be sending spam through my server
  • hMailServer can't connect to the database
  • PHPWebAdmin does not work

Error messages

If you get a error messbage from hMailserver when a prolem occurs, you can check the error message reference. This document contains a list with descriptions of the error messages hMailServer generates.
