The GreyListingWhiteAddresses collection contains IP addresses which won't be effected by grey listing.

Properties

Property Count As Long

The number of objects in the collection.

Property Item(Index As Long) As GreyListingWhiteAddress

Returns an object from the collection based on it's index in the collection.

Property ItemByDBID(DBID As Long) As GreyListingWhiteAddress

Returns an object from the collection based on it's database identifier.

Methods

Function Add() As GreyListingWhiteAddress

Adds a new object to the collection.

Sub DeleteByDBID(DBID As Long)

Deletes the object with the specified database identifier.

Sub Refresh()

Refreshes the collection from the database.
