The DistributionList object contains the settings for a hMailServer distribution list.

Version

The below documentation is valid for hMailServer 4.1 and later.

Properties

Property Active As Boolean

The distribution list is active.

Property Address As String

The address of the distribution list.

Property Recipients As DistributionListRecipients

A collection containing the recipients of the distribution list.

Property RequireSenderAddress As String

The distribution list only allows messages from this address.

Property ID As Long

The database identifier for the distribution list.

Property RequireSMTPAuth As Boolean

hMailServer should require SMTP authentication when messages are delivered to the distribution list.

Methods

Sub Delete()

Deletes the distribution list.

Sub Save()

Saves the distribution list.
