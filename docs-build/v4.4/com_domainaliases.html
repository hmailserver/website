The DomainAliases collection contains the aliases of a domain set up in hMailServer.

Version

The below documentation is valid for hMailServer 4.2 and later.

Properties

Property Count As Long

The number of objects in the collection.

Property Item(Index As Long) As DomainAlias

Returns an domain alias from the collection based on it's index in the collection.

Property ItemByDBID(DBID As Long) As DomainAlias

Returns an domain alias from the collection based on it's database identifier.

Methods

Function Add() As DomainAlias

Adds a new domain alias to the collection.

Sub Delete(Index As Long)

Deletes the domain alias with the specified index.

Sub DeleteByDBID(DBID As Long)

Deletes the domain alias with the specified database identifier.

Sub Refresh()

Refreshes the collection from the database.
