Properties

Property Accounts As Accounts

Returns a collection containing the accounts connected to this domain.

Property Active As Boolean

Returns true if the domain is active. False otherwise.

Property ADDomainName As String

The active directory domain this domain will be synchronised to.

Property Aliases As Aliases

Returns a collection containing the aliases connected to this domain.

Property DistributionLists As DistributionLists

Returns a collection containing the distribution lists connected to this domain.

Property DomainAliases As DomainAliases

Returns the domain aliases for this domain.

Property ID As Long

The unique database identifier for the domain.

Property Name As String

The name of this domain.

Property MaxAccountSize As Long

Maximum size of accounts created in this domain.

Property MaxMessageSize As Long

Maximum message size when sending from this domain.

Property MaxNumberOfAccounts As Long

Maximum number of accounts which can be added to this domain.

Property MaxNumberOfAccountsEnabled As Boolean

Enable maximum number of accounts.

Property MaxNumberOfAliases As Long

Maximum number of aliases which can be added to this domain.

Property MaxNumberOfAliasesEnabled As Boolean

Enable maximum number of aliases.

Property MaxNumberOfDistributionLists As Long

Maximum number of distribution lists which can be added to this domain

Property MaxNumberOfDistributionListsEnabled As Boolean

Enable maximum number of distribution lists.

Property Postmaster As String

The post master address for this domain. Also called catch-all address.

Methods

Sub Delete()

Deletes the domain from the database

Sub Save()

Saves the domain in the database.

Sub SynchronizeDirectory()

Synchronizes this domain towards active directory.
