The hMailServer.AntiSpam object contains settings that relates to the hMailServer spam protection.

Properties

Property AddHeaderReason As Boolean

Add header X-hMailServer-Reason when spam message is found.

Property AddHeaderSpam As Boolean

Add header X-hMailServer-Spam when spam message is found.

Property Backup As BackupSettings

Returns an object of type Backup that contains the backup settings.

Property AntiSpamAction As eAntiSpamAction

The action to take when a message has been detected as spam.

Property CheckHostInHelo As Boolean

Check host specified in HELO command.

Property GreyListingEnabled As Boolean

Enables and disables grey listing

Property GreyListingFinalDelete As Long

GreyListing - Delete used triplet after this time (hours).

Property GreyListingInitialDelay As Long

GreyListing - Delay before accepting messages (minutes).

Property GreyListingInitialDelete As Long

GreyListing - Delete unused triplet after this time (hours).

Property GreyListingWhiteAddresses As GreyListingWhiteAddresses

Collection of IP addresses excluded from grey listing.

Property PrependSubject As Boolean

Prepend message subject on spam messages.

Property PrependSubjectText As String

Text to prepend to message subject.

Property SURBLServers As SURBLServers

Collection of SURBL servers.

Property WhiteListAddresses As WhiteListAddresses

Collection of whitelisted IP and email addresses.
