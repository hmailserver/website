The SURBLServers collection contains the SURBL servers defined in the hMailServer installation.

Properties

Property Count As Long

The number of objects in the collection.

Property Item(Index As Long) As SURBLServer

Returns an object from the collection based on it's index in the collection.

Property ItemByDBID(DBID As Long) As SURBLServer

Returns an object from the collection based on it's database identifier.

Property ItemByDNSHost(sDNSHost As String) As SURBLServer

Returns an object from the collection based on it's DNS host.

Methods

Function Add() As SURBLServer

Adds a new SURBL server to the collection.

Sub DeleteByDBID(DBID As Long)

Deletes the SURBL server with the specified database identifier.

Sub Refresh()

Refreshes the collection from the database.
