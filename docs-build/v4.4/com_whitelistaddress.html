The WhiteListAddress object holds an IP address range and / or email address which should be excluded from spam protection.

Properties

Property Description As String

A textual description of the record.

Property EMailAddress As Long

The email address which should be excluded from spam protection (wildcards allowed).

Property ID As Long

The unique database identifier for the object.

Property LowerIPAddress As String

The lower bound of the IP range which should be excluded from spam protection.

Property UpperIPAddress As String

The upper bound of the IP range which should be excluded from spam protection.

Methods

Sub Save()

Saves the object in the database.
