The IPHomes collection contains the IP addresses that hMailServer should use when multihoming is enabled.

Version

The below documentation is valid for hMailServer 4.2 and later.

Properties

Property Count As Long

The number of objects in the collection.

Property Item(Index As Long) As IPHome

Returns an IPHome from the collection based on it's index in the collection.

Property ItemByDBID(DBID As Long) As IPHome

Returns an IPHome from the collection based on it's database identifier.

Methods

Function Add() As IPHome

Adds a new IP home to the collection.

Sub DeleteByDBID(DBID As Long)

Deletes the IP home with the specified database identifier.

Sub Refresh()

Refreshes the collection from the database.
