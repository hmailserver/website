The Message object is available in several events and let you retrieve information on the active message.

Version

The below documentation is valid for hMailServer 4.2 and later.

Methods

Sub AddRecipient(sName As String, sAddress As String)

This method lets you add an recipient to the message. If the recipient name is unknown, specify an empty string for that parameter.

Sub ClearRecipients()

This method clears all recipients for the current message. All recipients are removed (To/CC/BCC). The MIME-header of the email is cleared as well.

Sub Save()

Saves the changes made to the object. If the message is new, this method will cause the message being delivered.

Properties

Property Attachments As Attachments

This property returns an collection containing the attachments connected to the message.

Property Body As String

Returns the plain-text contents of this message.

Property Date As String

Returns the Date-header for this message. In hMailServer 4.0 and earlier, this property was read-only. Note that there is no guarantee that  the value of this header is correct, since it is the sender that puts a value in this header.

Property Filename As String

Every hMailServer message is stored on a file on the disk. This property returns the name of this file.

Property EncodeFields As Boolean

Instructs hMailServer to try to MIME-decode and encode the contents of header fields when they are being edited using the API. When a header field value is updated using the COM API, and EncodeFields is true, hMailServer will try to MIME-encode any non-ascii characters. If EncodeFields is set to true (default), hMailServer will try to MIME-decode the value of header fields before being returned to the COM client.

Property From As String

This property returns the content of the From MIME-header of the email.

Property FromAddress As String

Returns the address that the sender gave in the MAIL FROM SMTP-command.

Property HeaderValue(FieldName) As String

The HeaderValue property lets you read, modify and add MIME-headers in the email message. For example, you can change the subject header by calling Message.HeaderValue("Subject") = "Something new". HeaderValue was added in hMailServer 4.1.

Function HasBodyType(BodyType As String) As Boolean

Use HasBodyType to determine whether a specific bode type exists. The body type should be a MIME main type plus a sub type, for example text/html. HasBodyType was added in hMailServer 4.1.

Property HTMLBody As String

The HTML body for this email. If this is empty, no HTML body exist. In hMailServer 4.0 and earlier, this property is read only.

Property ID As Long

The unique database identifier for this email.

Property InternalDate As Variant

The internal date and time of this message. Use this property to retrieve a timestamp for when the message was created in the hMailServer installation. This property is read-only.

Property Recipients As Recipients

Returns a collection containing all recipients for this email.

Property Size As Long

Returns the current size of the email message. For performance reasons, this property might not return the correct value for unsaved messages.

Property State As Long

Returns the current state of this message. 1 means that it is in the delivery queue. 2 means that it has been delivered.

Property Subject As String

Returns the subject MIME header for this message.

Property To As String

Returns the To MIME header for this message.
