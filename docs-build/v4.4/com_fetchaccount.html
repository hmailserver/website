FetchAccount is same as External account and is the feature used to download messages from external servers.

Version

The below documentation is valid for hMailServer 4.2 and later.

Properties

Property AccountID As Long

The database identifier for the account that this external account is connected to.

Property DaysToKeepMessages As Long

The number of days hMailServer should leave messages on the external server before deleting it.

Property Enabled As Boolean

If the external account is active, true is returned. Otherwise false.

Property ID As Long

The database identifier for this external account.

Property MinutesBetweenFetch As Long

The number of minutes between hMailServer checks the external account for new messages. It's not recommended that you set this value to lower than 30 (minutes).

Property Name As String

The name of this external account. Can be anything (but should not be empty).

Property Password As String

The password hMailServer should use when logging on the external POP3 account

Property Port As Long

The port number on the external POP3 server hMailServer should connect to. Normally 110.

Property ProcessMIMEDate As Boolean

Process receive date in Received header. If this option is enabled, hMailServer will set the internal date of the message to the date in the latest Received-header, instead of using the current date.

Property ProcessMIMERecipients As Boolean

If this option is selected, hMailServer will forward the message to the recipients in the MIME headers instead of sending it to the account which this external account belongs to.

Property ServerAddress As String

The host name of the external POP3 server.

Property ServerType As Long

The type of external server. Currently only 0 (POP3).

Property Username As String

The username hMailServer should use when logging on the external POP3 account

Methods

Sub DownloadNow()

This method triggers a download of messages from the external account. This is done internally by changing the "Next download time" to now, and then telling the ExternalFetchManager that messages should be downloaded. This has the effect that messages will be downloaded as soon as possible. If a download from this account is already ongoing, this command won't have any effect. If the maximum number of simultaneous downloads are already ongoing, the download for this external account will be scheduled until one of these downloads have been completed.

Sub Save()

Saves the external account / fetch account in the database. If the object already exists, it's updated.
