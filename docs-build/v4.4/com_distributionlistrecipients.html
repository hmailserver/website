The DistributionListRecipients collection contains the email addresses connected to a distribution list.

Version

The below documentation is valid for hMailServer 4.0 and later.

Properties

Property Count As Long

The number of objects in the collection.

Property Item(Index As Long) As DistributionListRecipient

Returns an address from the collection based on it's index in the collection.

Property ItemByDBID(DBID As Long) As DistributionListRecipient

Returns an address from the collection based on it's database identifier.

Methods

Function Add() As DistributionListRecipient

Adds a new recipient to the collection.

Sub DeleteByDBID(DBID As Long)

Deletes the recipients with the specified database identifier.
