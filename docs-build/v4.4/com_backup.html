The backup object contains information regarding a backup made by hMailServer.

Version

The below documentation is valid for hMailServer 4.2 and later.

Properties

Property ContainsDomains As Boolean

True if the backup contain domains.

Property ContainsMessages As Boolean

True if the backup contain messages.

Property ContainsSettings As Boolean

True if the backup contain settings.

Property DeleteObjectsNotInBackup As Boolean

If this property is set to true, hMailServer will delete objects that does not exist in the backup when restoring.

Property OverwriteObjects As Boolean

If this property is set to true, hMailServer will overwrite objects in the installation that exists in the backup file, when restoring.

Property RestoreDomains As Boolean

Set this property to true if you want hMailServer to restore domains in the backup when running the restore

Property RestoreMessages As Boolean

Set this property to true if you want hMailServer to restore messages in the backup when running the restore

Property RestoreSettings As Booleann

Set this property to true if you want hMailServer to restore settings from the backup when running the restore

Methods

Sub StartRestore()

This option restores the backup. This is done asynchronously - the method returns immediately. Restore result can be found in the hMailServer backup/restore-log.
