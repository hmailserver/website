The ServerMessages collection contains the auto-generated messages that hMailServer sends to clients, for example when a virus has been detected in a message. The list of messages is pre-defined and it's not possible to add or delete messages - just to modify them.

Properties

Property Count As Long

The number of objects in the collection.

Property Item(Index As Long) As ServerMessage

Returns an object from the collection based on it's index in the collection.

Property ItemByDBID(DBID As Long) As ServerMessage

Returns an object from the collection based on it's database identifier.

Methods

Sub Refresh()

Refreshes the collection from the database.
