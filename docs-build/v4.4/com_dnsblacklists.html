The DNSBlackLists collection contains the DNS blacklists set up in hMailServer.

Version

The below documentation is valid for hMailServer 4.0 and later.

Properties

Property Count As Long

The number of objects in the collection.

Property Item(Index As Long) As DNSBlackList

Returns an DNSBlackList from the collection based on it's index in the collection.

Property ItemByDBID(DBID As Long) As DNSBlackList

Returns an DNSBlackList from the collection based on it's database identifier.

Property ItemByDNSHost(sDNSHost As String) As DNSBlackList

Returns an DNSBlackList from the collection based on it's DNS host.

Methods

Function Add() As DNSBlackList

Adds a new DNSBlackList to the collection.

Sub DeleteByDBID(DBID As Long)

Deletes the DNSBlackList with the specified database identifier.

Sub Refresh()

Refreshes the collection from the database.
