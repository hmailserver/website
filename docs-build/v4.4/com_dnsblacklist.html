The DNSBlackList object represents a DNS blacklist set up in hMailServer.

Version

The below documentation is valid for hMailServer 4.0 and later.

Properties

Property Active As Boolean

The DNS blacklist is active and, use by hMailServer.

Property DNSHost As String

The host hMailServer should query.

Property ExpectedResult As String

The IP address the query will resolve to if host is in black list.

Property ID As Long

The unique database identifier for the object.

Property RejectMessage As String

The message to send to the client if server rejects message.

Methods

Sub Save()

Saves the DNS blacklist in the database.
