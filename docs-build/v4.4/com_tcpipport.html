The TCPIPPort object represents a TCP/IP port hMailServer should listen for incoming traffic on.

Properties

Property ID As Long

The unique database identifier for the object.

Property PortNumber As String

The TCP/IP port number.

Property Protocol As eSessionType

The type of the session. Can be eSTSMTP = 1, eSTPOP3 = 3, eSTIMAP = 5

Methods

Sub Save()

Saves the object in the database.
