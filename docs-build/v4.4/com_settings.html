The cache object contains settings that relates to the hMailServer caching functionality.

Version

The below documentation is valid for hMailServer 4.2 and later.

Properties

Property AllowSMTPAuthPlain As Boolean

Allow plain SMTP authentication.

Property AntiVirus As AntiVirus

Returns an object of type AntiVirus that contains the anti virus settings.

Property Backup As BackupSettings

Returns an object of type Backup that contains the backup settings.

Property Cache As Cache

Returns an object of type Cache that contains the cache settings.

Property DenyMailFromNull As Boolean

This property lets you specify whether hMailServer should allow SMTP-deliveries without sender address.

Property DNSBlackLists As DNSBlackLists

Returns a collection of the DNS blacklists.

Property HostName As String

The host name used by hMailServer when delivering messages (used in SMTP HELO command).

Property IMAPPort As Long

The TCP/IP port that the IMAP server should use.

Property IPHomes As IPHomes

Returns a collection of IP homes used by hMailServer when multihoming is enabled.

Property ListenOnAllAddresses As Boolean

Should hMailServer listen on all available IP addresses?

Property Logging As Logging

Returns an object of type Logging that contain all log-related settings.

Property MaxDeliveryThreads As Long

The maximum number of SMTP delivery threads.

Property MaxMessageSize As Long

The maximum message size that this server should allow.

Property MaxPOP3Connections As Long

The maximum number of simultaneous POP3 connections.

Property MaxSMTPConnections As Long

The maximum number of simultaneous SMTP connections.

Property MirrorEMailAddress As String

The mirror address hMailServer should send messages to.

Property POP3Port As Long

The TCP/IP port used by the POP3 server.

Property Routes As Routes

Returns a collection containing the routes used by hMailServer.

Property RuleLoopLimit As Long

The maximum number of times a message can be processed by rules.

Property Scripting As Scripting

Returns an object of type Scripting that contain all script-related settings.

Property SecurityRanges As SecurityRanges

Returns a collecton containing the SecurityRanges / IP ranges used by hMailServer.

Property SendStatistics As Boolean

This option lets you specify whether hMailServer should send delivery statistics to hMailServer.com

Property ServiceIMAP As Boolean

This option lets you specify whether IMAP should be enabled.

Property ServicePOP3 As Boolean

This option lets you specify whether POP3 should be enabled.

Property ServiceSMTP As Boolean

This option lets you specify whether SMTP should be enabled.

Property SMTPMinutesBetweenTry As Long

Number of minutes between each try when delivering an e-mail.

Property SMTPNoOfTries As Long

Number of retries when SMTP server delivers an e-mail.

Property SMTPPort As Long

The TCP/IP port to use for the SMTP server.

Property SMTPRelayer As String

The SMTP server that hMailServer should deliver all messages to.

Property SMTPRelayerPort As Long

The SMTP port to use when delivering to the SMTP relayer.

Property SMTPRelayerRequiresAuthentication As Boolean

Set to true if the SMTP relayer requires authentication. False otherwise.

Property SMTPRelayerUsername As String

The user name that hMailServer should use when delivering e-mail to the SMTP relayer.

Property TarpitCount As Long

The tarpit count.

Property TarpitDelay As Long

The tarpit delay.

Property UseDeliveryLog As Boolean

True if hMailServer should use the delivery log. False otherwise.

Property UseMXChecks As Boolean

True if hMailServer should use MX checks during spam protection.

Property UserInterfaceLanguage As String

The language in which the user interface should be shown.

Property UseSPF As Boolean

Set this option to true if hMailServer should do SPF checks during spam protection. False otherwise.

Property WelcomeIMAP As String

The welcome / banner message that the IMAP server should use when a client has connected to the server.

Property WelcomePOP3 As String

The welcome / banner message that the POP3 server should use when a client has connected to the server.

Property WelcomeSMTP As String

The welcome / banner message that the SMTP server should use when a client has connected to the server.

Methods

Sub SetSMTPRelayerPassword(newVal As String)

Sets the password that hMailServer use when delivering a message to an external SMTP server and SMTP authentication is enabled.
