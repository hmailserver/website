Description

The ServerMessages object is a collection of customizable server messages.

Methods

Refresh()
Refreshes the collection.

Properties

long Count
Number of items in the collection.
(read-only)
ServerMessage Item(long Index)
Returns a object by its given index.
(read-only)
ServerMessage ItemByDBID(long DBID)
Returns a object by its database identifier
(read-only)
ServerMessage ItemByName(string sName)
Returns a object by its name
(read-only)
