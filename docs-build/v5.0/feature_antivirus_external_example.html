Overview

This page contains a list of virus command line examples which works with hMailServer.

AVG Free 7

Command line: "C:\Program Files\Grisoft\AVG Free\avgscan.exe" /EXT=* /NOBOOT /NOMEM /SCAN /NOSELF /NOHIMEM /ARC "%FILE%"

Return value: 6

AVG Free 8

Note that earlier versions of AVG Free 8's avgscanx.exe did not return a value indicating whether a virus was found or not. To be able to use the command line below, make sure you have an up to date version of AVG Free 8. As of 2008-07-07, the version published on http://free.avg.com/ is up to date. Command line: "C:\Program Files\AVG\AVG8\avgscanx.exe" /EXT=* /NOBOOT /NOMEM /SCAN="%FILE%" /NOSELF /NOHIMEM /ARC

Return value: 5
